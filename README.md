## 📖 About

End Portal Finder calculates End Portal room coordinates from the world seed, showing all 128 strongholds sorted by distance with HUD markers and map pins.

---

## ✨ Features
<a name="features"></a>

- **All 128 Strongholds** — every End Portal location computed instantly.
- **Distance Sort** — nearest stronghold at the top.
- **Map Pins** — marks each on the minimap.
- **Nether Shortcut** — equivalent Nether coordinates shown.
- **HUD Arrow** — compass arrow points to target.
- **Eye Count Estimate** — tells you how many Eyes to prepare.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
